# Uni-Year-1-Coursework
This repository contains the two main pieces of  coursework I completed for the Programming 1 and Programming 2 modules during my first year of uni.

## Projects

### Python Pattern Generator

A Python program developed to generate a specified pattern based on user-defined input parameters.

The required pattern arrangement was provided by the university as part of the coursework, with different students being assigned different pattern arrangements. The program was developed to correctly generate the assigned pattern based on the user's input.

**Skills demonstrated:**
- Python
- User input
- Conditional logic
- Mathematical calculations
- Program structure


### Dart Phone Simulation

A Dart program simulating basic phone functionality, including actions that affect the phone's battery level.

**Skills demonstrated:**
- Dart
- Object-oriented programming
- State management
- Conditional logic
- Modelling the behaviour of a simple system
